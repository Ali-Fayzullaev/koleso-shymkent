# Колесо Шымкент

Лендинг для Instagram-страницы по продаже автомобилей в Шымкенте.

- **Сайт:** https://koleso-shymkent.netlify.app
- **Репозиторий:** https://github.com/Ali-Fayzullaev/koleso-shymkent
- **Netlify (админка):** https://app.netlify.com/projects/koleso-shymkent

## Как это работает (деплой)

Сайт настроен на автодеплой: **push в ветку `master` на GitHub → Netlify сам собирает и выкладывает сайт.** Вручную ничего катить не нужно.

1. Правите файлы (см. таблицу ниже)
2. `npm run build` — локально проверить, что всё собирается
3. `git add -A && git commit -m "..." && git push`
4. Через 10–30 секунд изменения на https://koleso-shymkent.netlify.app

Netlify запускает `npm run build` сам на своей стороне при каждом пуше — можно даже не собирать локально, но лучше проверить перед пушем.

## Что редактировать, а что — нет

Это React-приложение, собираемое esbuild'ом. **Итоговые файлы генерируются автоматически** — руками их менять нельзя, правки потеряются при следующей сборке.

| Файл/папка | Можно редактировать? | Что это |
|---|---|---|
| `src/App.jsx` | ✅ Да | Вся разметка и структура страницы (JSX) |
| `src/config.js` | ✅ Да | **Сюда в первую очередь**: WhatsApp-номер, текст сообщения, Instagram-ссылка, статистика (подписчики/посты/годы), реквизиты ИП |
| `src/GlassSurface.jsx/.css` | ✅ Да (осторожно) | Стеклянный эффект (React Bits), используется в шапке и hero |
| `styles.css` | ✅ Да | Все стили, минифицированы в несколько длинных строк — редактировать через добавление новых правил в конец файла проще, чем править существующие строки |
| `assets/*.png` (source) | ✅ Да | Исходники изображений (для повторной генерации webp) |
| `script.js`, `script.css` | ❌ Нет | Генерируются из `src/` командой `npm run build` |
| `publish/**` | ❌ Нет | Копия для деплоя, синхронизируется автоматически (`tools/sync-publish.cjs`) при сборке |
| `backup-original/` | — | Три исходных файла (до переписывания на React), просто архив |
| `qa/` | — | Скриншоты и результаты `npm run check` |

## Команды

```bash
npm install        # один раз
npm run build      # собрать script.js/script.css и синхронизировать publish/
npm run preview    # локальный просмотр: http://127.0.0.1:4173
npm run check      # автопроверка адаптивности/ссылок/меню/FAQ (tools/check.cjs)
```

## Важно не перепутать

- Это **отдельный проект**, не путать с папкой `s3` рядом (это сайт автодетейлинга, другой бизнес, другой репозиторий).
- Аккаунты: GitHub — `Ali-Fayzullaev`, Netlify — тот же email. CLI на этой машине уже авторизован, повторный логин не нужен.
- Реквизиты ИП и статистика (подписчики/посты) заданы вручную в `src/config.js` — их никто не сверяет с реальным Instagram автоматически, обновлять при изменении.

## История изменений

- **Первая версия** — простой лендинг на чистом HTML/CSS/JS (сохранён в `backup-original/`).
- **Переписан на React** — esbuild-сборка, добавлен `GlassSurface` (React Bits), новые фото (`assets/hero.webp`, `assets/interior.webp`), шрифт Manrope.
- **Настроен GitHub + автодеплой Netlify** — репозиторий создан, привязан к Netlify (Site settings → Build & deploy → Link repository). Заодно починена сборка: `npm run build` раньше обновлял только корневой `script.js`, но не папку `publish/`, которую реально отдаёт сайт — добавлен `tools/sync-publish.cjs`, который копирует всё нужное в `publish/` при каждой сборке.
- **Добавлен блок реквизитов** — ИП, БИН, адрес, телефон, email, вид деятельности в футере. Изначально сделан сворачиваемым (как FAQ), затем переделан на **всегда видимый** — реквизиты не должны быть спрятаны за кликом.
- **Заменены иконки на настоящие бренд-логотипы** — иконка WhatsApp была абстрактной и выглядела как клякса на маленьком размере, заменена на официальный узнаваемый глиф. Иконка Instagram была схематичной (рамка+точка), заменена на настоящий градиентный логотип (компонент `InstagramLogo` в `App.jsx`).

Фотографии на сайте — иллюстрации (сгенерированы), не реальные объявления.
