# Колесо Шымкент

Откройте index.html двойным щелчком. Готовая сборка и все изображения, шрифт и стили находятся рядом; CDN не нужен.

Для разработки: npm install, затем npm run build. Предпросмотр: npm run preview (http://127.0.0.1:4173).

- src/App.jsx — React-разметка.
- src/config.js — WhatsApp, Instagram и статистика.
- src/GlassSurface.jsx и src/GlassSurface.css — адаптация предоставленного компонента React Bits.
- styles.css — дизайн и мобильная версия.
- assets/hero.webp и assets/interior.webp — иллюстративные изображения, созданные встроенным image_gen.
- tools/check.cjs — проверки адаптивности, ссылок, меню и FAQ.
- qa/ — снимки страницы и результаты проверок.
- backup-original/ — первоначальные три файла.

После изменения src запустите npm run build. script.js и script.css — готовые файлы сборки.
Статистика перенесена из исходного сайта и не проверена в Instagram. Фотографии не являются реальными объявлениями.
